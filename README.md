# ✨ magiClaude

magiClaude makes your Claude Desktop session easy and fun to read:

beautiful, colorful, code highlighting, charts, dynamic buttons (quote, copy, choose), correct BiDi (RTL/LTR).

It doesn't modify Claude's core - only a hook.

| Without magiClaude | With magiClaude |
|:------------------:|:---------------:|
| ![Without magiClaude](assets/before.png) | ![With magiClaude](assets/after.png) |

## Install · Update · Uninstall

Copy & paste into Claude Desktop:

```text
Install YitshakS/magiClaude marketplace plugin
```

```text
Update YitshakS/magiClaude marketplace plugin
```

```text
Uninstall YitshakS/magiClaude marketplace plugin
```
